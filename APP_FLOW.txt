================================================================
TOKEN / SESSION FLOW
================================================================

Login / Signup
  └── JWT stored in flutter_secure_storage (via TokenStorage)
      ├── accessToken  — sent as Bearer header on every API call
      ├── userId       — decoded from JWT sub claim
      ├── userRole     — used for dashboard routing
      └── userEmail    — used in profile pages

Logout (any role)
  └── TokenStorage.clearAll() → back to WelcomePage
      (no server call — token is simply discarded locally)

401 response from any API call
  └── DioClient interceptor clears tokens automatically


================================================================
API SERVICES OVERVIEW
================================================================

AuthApiService
  ├── POST /auth-service/api/auth/login
  ├── POST /auth-service/api/auth/signup
  └── logout()  (local only, no server call)

TripApiService
  ├── POST /trip-service/api/trips/offer          (create trip)
  ├── POST /trip-service/api/trips/cancel         (cancel trip)
  ├── GET  /trip-service/api/trips/active/driver/{id}      (driver's trips)
  ├── GET  /trip-service/api/trips/search/near-source      (search)
  ├── GET  /trip-service/api/trips/search/near-destination (search)
  ├── GET  /trip-service/api/trips/search/matching-route   (search)
  ├── GET  /trip-service/api/admin/trips/upcoming          (admin)
  ├── GET  /trip-service/api/admin/trips                   (admin)
  ├── GET  /trip-service/api/admin/trips/{id}              (admin detail)
  └── GET  /trip-service/api/admin/bookings                (admin)

BookingApiService
  ├── POST /trip-service/api/rides/book           (join trip)
  ├── POST /trip-service/api/rides/cancel         (cancel booking)
  └── GET  /trip-service/api/rides/active/passenger/{id}  (my bookings)

UserApiService
  ├── GET  /user-service/api/users/{userId}        (user profile)
  ├── GET  /user-service/api/vehicles/{userId}     (user vehicles)
  ├── GET  /user-service/api/admin/drivers         (admin list)
  ├── GET  /user-service/api/admin/passengers      (admin list)
  ├── POST /user-service/api/admin/drivers/{id}/approve
  ├── POST /user-service/api/admin/drivers/{id}/reject
  ├── DELETE /user-service/api/admin/drivers/{id}
  └── DELETE /user-service/api/admin/passengers/{id}
